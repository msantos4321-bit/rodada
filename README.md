# Rodada

App para motociclistas (Android): rutas con curvas, navegación por voz, inclinación y aceleración, detección de caídas, garaje y grupo de amigos (ruta de la semana, chat y mapa en vivo).

Descarga: https://github.com/msantos4321-bit/rodada/releases/latest/download/Rodada.apk

- Mapas © OpenStreetMap y OpenFreeMap · rutas Valhalla (FOSSGIS) · búsqueda Photon · clima Open-Meteo · gasolineras Overpass.
- El grupo vive en Supabase (tablas `rd_*`, ver `supabase/01_rodada.sql`).
- La firma se hace en GitHub con el secreto `RODADA_FIRMA` (nunca en el código).
